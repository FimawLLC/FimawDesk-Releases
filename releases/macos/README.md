# FimawDesk for macOS

macOS builds are published in this folder.

- **`.dmg`** — double-click to open, drag FimawDesk into the Applications folder, then launch it.

**First launch:** if Gatekeeper says it is from an unidentified developer, right-click (Control-click) the app and choose **Open**.

**File names:** `fimawdesk-<version>-<arch>.dmg` where `<arch>` is `x86_64` (Intel) or `aarch64` (Apple Silicon). The universal build covers both on a single machine.
