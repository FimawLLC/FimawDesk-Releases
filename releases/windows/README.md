# FimawDesk for Windows

Windows installers are published in this folder.

- **`.exe`** — the regular executable / portable build. No installer needed; run it, or keep it in a folder.
- **`.msi`** — classic Windows installer (adds Start-menu shortcut, uninstall entry). Run it to install.
- **`windows-x86_64` / `windows-aarch64`** — folders of unsigned/signed release artifacts when available.

**Install:** download the `.msi` for your architecture (`x86_64` = 64-bit, `aarch64` = ARM) and run it. Pick the `.exe` instead if you prefer a portable copy.

Filenames: `fimawdesk-<version>-<arch>.<ext>`.
