# FimawDesk for Android

Android builds are published in this folder.

- **`.apk`** — install directly on the device (enable “Install unknown apps” for this file manager on the first install).
- **Universal `.apk`** — one file covering all Android CPU architectures (ARM, x86, x86_64).

**File names:** `fimawdesk-<version>-<arch>.apk` and `fimawdesk-<version>-universal.apk`.
