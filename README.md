# FimawDesk - Releases

**FimawDesk** is a remote-desktop client by [Fimaw LLC](https://www.fimaw.com).

Installers and release builds that end users can download directly are published in **this public repository**. The complete, private source code lives in a separate, private repository and is not published here.

## How releases work

- Build artifacts (`.exe` / `.msi`, `.dmg`, `.deb` / `.rpm` / `.AppImage`, `.apk`, `.ipa`) are published under `releases/<platform>/`.
- The latest release on GitHub Releases points at these assets.
- Each platform folder is updated on every publish.
